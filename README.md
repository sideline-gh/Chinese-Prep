# Hanzi Stroke Book

A study page for Chinese lessons 1 to 3 (45 words, 61 characters), made for midterm prep.

- Tap any character to watch its stroke order, see every stroke as a step diagram, and practice drawing it.
- Tap the speaker buttons to hear a word or character. This uses your device's own Chinese voice.
- Mark characters as learned, hide learned words, or blur the pinyin and meaning to test yourself.

Progress is saved in your own browser only.

The page is a single `index.html` file. It loads stroke data from the hanzi-writer-data package and the Hanzi Writer library through jsDelivr, so it needs an internet connection.
